# Financial definitions

`total revenue = AdMob revenue + in-app net revenue + other app revenue`

`marketing profit = total revenue − Google Ads spend`

`operating profit = marketing profit − direct expenses − allocated shared expenses`

`ROAS = total revenue / ad spend`; `ROI = marketing profit / ad spend`;
`gross margin = operating profit / total revenue`. Zero denominators return null.
Profit status uses an organization-configurable decimal tolerance. Aggregate underlying
facts, never rounded ratios. Mixed currencies remain separate unless a dated explicit FX
module is enabled.
