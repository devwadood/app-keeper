# Google Play setup

Administrators enable Developer Reporting and Cloud Storage JSON APIs. Customers add the
Google identity to Play Console with global View app information and optional View
financial data only, copy the private `pubsite_prod_rev_…` report bucket, create a Play
profile, validate listing/reading, and select apps.

The importer must treat monthly exports as delayed and mutable, parse UTF-16 CSV, retain
object generation/checksum/provenance, upsert by stable source keys, and reconcile
preliminary sales with finalized earnings.
